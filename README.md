# 应老师财税AI工具箱

实用财税单页工具集合，所有工具均为单个 HTML 文件，浏览器打开即用，数据本地处理不联网。

## 工具列表

### 🧮 产值核算工具 v3.2
工业产值自动核算，支持多产品、多月度、多费用项归集。

### 📋 小规模纳税人凭证申报表工具 v3.7
增值税 + 所得税一体化核算，申报表 25 栏完整版，复合分录、利润表、导入导出 Excel。

### 🎂 生日快乐提醒工具
Excel 生日数据导入，自动计算倒计时，按年/月筛选，到期自动提醒。

### 🔒 财务数据脱敏器
Excel 敏感字段批量脱敏（身份证/手机号/银行卡号等），本地处理不外泄。

所有工具：单文件 HTML，双击即用，数据本地处理，不上传服务器。

## 使用方式

1. 下载对应的 `.html` 文件
2. 双击用浏览器打开
3. 数据完全在本地浏览器中处理，不会上传到任何服务器
